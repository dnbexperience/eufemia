# Wizard submit demo for the step change fix

Demos for the pull request that keeps a submit pending until the Wizard step change it starts is done.

- `issue/` uses `https://pkg.pr.new/@dnb/eufemia@ffc6630`, the build of main the PR is based on.
- `fix/` uses the PR build `https://pkg.pr.new/@dnb/eufemia@2eda347`.

The app code is the same in both folders. Only the `@dnb/eufemia` version in `package.json` differs.
