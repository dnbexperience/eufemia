## November, 2. 2026

- [Design tokens](/web/styling-and-themes/design-tokens/colors#migrating-information-and-neutral-colors): information colors are now blue across DNB, Sbanken and Carnegie. Neutral colors and secondary text have been adjusted. Applications using custom neutral backgrounds or foundation color variables should follow the migration guidance when upgrading.

## October, 30. 2026

- New component: [TableOfContent](/uilib/components/table-of-content) for accessible navigation within long pages, with nested section links, a current-section indicator, and a collapsible list on smaller screens.

## October, 23. 2026

- New component: [Popover](/web/components/popover) for accessible floating panels anchored to a trigger, with flexible content.
- [Card.Info](/web/components/card/#cardinfo): added information cards with image and video layouts, close buttons, and media controls.
- [CopyOnClick](/web/components/copy-on-click): added an accessible copy button with confirmation feedback.
- [SidebarMenu](/web/patterns-and-extensions/sidebar-menu): added compact responsive navigation with an expandable icon rail and scrolling that reveals opened accordion content.
- [Typography](/web/styling-and-themes/design-tokens/typography): aligned font sizes and line heights with Figma design tokens, including larger Carnegie headings and increased line heights for responsive headings.

## September, 29. 2026

- [Tabs](/web/components/tabs): added tooltips for disabled tabs.
- [Company logo library](/collections/logos) and [public asset CDN](/web/ai-tools-and-resources/asset-cdn/): added documentation for versioned company logos, fonts, icons, and other Eufemia assets.
- [Textarea](/web/components/textarea): added a resize handle when automatic resizing is enabled.
- New [Icon](/collections/icons): `sidebar`.

## September, 16. 2026

- New extension: [SidebarMenu](/web/patterns-and-extensions/sidebar-menu) for persistent navigation with switchable sections, deeply nested accordion groups, and declarative or data-driven composition.
- New [Icons](/collections/icons):
  - `add_reaction`
  - `solve`

## September, 10. 2026

- [Animation Principles](/design-foundations/motion-principles/): added visual guidance for motion character, easing, and common interface transitions.
- [Icon](/web/components/icon/#animated-icons): added opt-in animated icons for interface feedback and transitions.
- [Tabs](/web/components/tabs): added an animated active underline.
- [Forms](/web/forms/): added a `radio-button` variant to Field.Selection, Field.Boolean, and Field.Toggle.
- [Autocomplete](/web/components/autocomplete), [Dropdown](/web/components/dropdown), [Field.Selection](/web/forms/base-fields/Selection), and [Field.MultiSelection](/web/forms/base-fields/MultiSelection): added opt-in virtualized lists for large data sets.

## September, 3. 2026

- [Accessibility](/web/accessibility/checklist/#find-in-page-for-collapsed-content): added `openOnFind` support to reveal collapsed content through browser find-in-page in supported browsers.
- [Typography](/web/layout-and-typography/typography/font-size/#optional-javascript-root-scaling): added opt-in iOS Dynamic Type scaling that preserves the default text size and follows changes to the system text-size setting.

## August, 14. 2026

## January, 30. 2020

### New DNB font

General information: All existing and new components uses the new (and slightly larger) text styles, but the existing height of the components is not affected by this and has NOT changed.

[Typography](/web/layout-and-typography/typography) changes:

- **h1** `DNB Sans Medium` 48px / 56px line height
- **h1 small** `DNB Sans Medium` 34px / 40px line height
- **h2** `DNB Sans Medium` 26px / 32px line height
- **h3 / Lead** `DNB Sans Medium` 20px / 28px line height
- **Body text** `DNB Sans Regular` 18px / 24px line height
- **Body text medium** `DNB Sans Medium` 18px / 24px line height
- **Small text** `DNB Sans Regular` 16px / 20px line height
- **Small text medium** `DNB Sans Medium` 16px / 20px line height
- **X-Small text** `DNB Sans Regular` 14px / 16px line height
