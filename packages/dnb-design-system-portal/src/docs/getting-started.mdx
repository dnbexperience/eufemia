Eufemia brings together DNB's design guidance, reusable assets, and interface components. Start with what you need, then choose your platform.

## Understand the shared principles

Read the [design principles](/design-foundations/design-principles/), [brand guidelines](/design-foundations/brand-guidelines/), and [motion principles](/design-foundations/motion-principles/). These explain the intent behind the interfaces we create.

## Find an asset

Browse [icons](/collections/icons/) and [company logos](/collections/logos/) under Collections. The [DNB logo guidance](/collections/logos/#dnb-brand-logos) explains the brand assets. Platform-specific import instructions live with the relevant component documentation.

## Choose your platform

Use the platform selector in the sidebar to choose Web, iOS, or Android. Each section holds its own setup, components, and implementation guidance. The iOS and Android sections are still being documented.

For Web, [render your first component](/web/get-started/quick-start/) or [set up Eufemia Web in Figma](/web/get-started/design-for-web/). Typography, layout, accessibility, and motion implementation guides currently belong to Web.

## Get help

[Contact the team](/about/contact/) for help finding the right resource. To improve the current Web documentation, [suggest a change](/web/contribute/suggest-edit/) or [contribute to Eufemia Web](/web/contribute/).
