# Icons library

This is a comprehensive list of all available icons, sorted by categories. Primary and secondary icons are shown together in this combined view. You may want to [read more](/icons/details) about [the differences](/icons/primary) and [how to import](/icons/secondary#react-example-usage) them.

- For web, icons are available as public [versioned SVG files](/uilib/usage/assets/#available-eufemia-assets) and ready-to-use [React components](/icons/secondary#react-example-usage).
- For Android, there are public [custom XML drawable packages](https://assets.eufemia.dnb.no/icons/dnb/eufemia-icons-xml.tgz) and [categorized XML drawable packages](https://assets.eufemia.dnb.no/icons/dnb/eufemia-icons-xml-categorized.tgz). Use the matching [versioned CDN path](/uilib/usage/assets/#stable-and-versioned-urls) for reproducible builds.
- Support for iOS with the PDF format was discontinued in [v10](/uilib/about-the-lib/releases/eufemia/v10-info/).

## Filled Icons

Some icons support a filled variant where the SVG paths are filled with `currentColor`. Use the toggle below to preview filled icons. Use the `fill` prop on `Icon`. See the [Icon component docs](/uilib/components/icon#filled-icons) for usage details.

## Animated Icons

Some icons have an optional animated import. Use the toggle below to see which icons support motion, then hover an icon to preview the animation. Animated icons use direct default imports rather than named imports. See the [Icon component docs](/uilib/components/icon#animated-icons) for where, why, and when to use them.
