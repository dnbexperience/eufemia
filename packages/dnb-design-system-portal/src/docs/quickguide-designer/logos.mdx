# Logos

## Brand Center

**Note:** If you have access to DNB's Brand Center, [you can find the logos under "Visuell identitet"](https://bc.dnb.no/brandcenter/no/dnbvisualguidelines/component/default/761).

## Brandbook

From the Brandbook PDF file, digital media should use the 3rd level logos (page 9).

## Developers

The DNB Logo can easily be used and [integrated into digital web products as a component](/uilib/components/logo).

Use the standalone company-logo catalogue for banks, partners, and other
companies. Native consumers can start with the public
[`logos/manifest.json`](https://assets.eufemia.dnb.no/logos/manifest.json),
which points to immutable, versioned PNG assets. React applications should use
the `@eufemia/logos` package. See the [Asset CDN company-logo
documentation](/uilib/usage/assets/#company-logos) for the URL and versioning
contract.
