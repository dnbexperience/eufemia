## Description

Use Button to start, confirm, or submit an action, such as "Add account" or "Save changes". Use [Anchor](/uilib/components/anchor) to navigate to another page or section.

## Import

```tsx
import { Button } from '@dnb/eufemia'
```

## Accessibility

Buttons support keyboard interaction: Tab moves focus, and Enter or Space activates the button. Keep the focus indicator visible and use a label that describes the action.

For buttons without visible text, follow the [icon-only button guidance](/uilib/components/button/demos/#icon-button).

## Typography

DNB primary, secondary and tertiary button labels use DNB Sans Text Medium,
following the brand guidance for calls to action. Unstyled buttons and the
other brands retain their existing weight. The text font is shared with
other interface content.

DNB labels use normalized font metrics and no additional upward adjustment.
Sbanken retains its existing label adjustment for Roboto. The font weight
and vertical alignment are separate choices; changing the weight is not a
centering correction.
