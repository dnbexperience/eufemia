## Import

```tsx
import { Logo } from '@dnb/eufemia'
```

## Description

A ready-to-use Logo component with the needed SVGs.

This component provides DNB brand-family logos. For banks, partners, and other
company logos, use the `@eufemia/logos` package or the public native
[company-logo CDN](/uilib/usage/assets/#company-logos).
