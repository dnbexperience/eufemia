## TableOfContentPreHydrationScript

Import this helper from `@dnb/eufemia/components/table-of-content/TableOfContentPreHydrationScript`. It restores the saved disclosure styling before first paint in SSR and static pages. Place it after the navigation markup and before application hydration. It accepts standard script attributes, including nonce, except children and dangerouslySetInnerHTML.

The same module exports getPreHydrationScript for HTML templates assembled outside React. See [disclosure persistence](/uilib/components/table-of-content/#responsive-layout-and-scrolling) for placement and usage.
