## Import

```tsx
import { Ingress } from '@dnb/eufemia/elements'
```

## Description

An ingress is a brief, introductory paragraph that follows immediately after the title of an article.

Ingress retains its Medium weight by default. For DNB introductory text,
the [brand guidance](/uilib/typography/#font-roles) specifies Regular:

```tsx
<Ingress weight="regular">A short introduction to the article.</Ingress>
```
