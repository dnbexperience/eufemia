## Import

```tsx
import * as Ai from '@dnb/eufemia/extensions/ai'
import '@dnb/eufemia/extensions/ai/style'
render(<Ai.ActivityText>Searching …</Ai.ActivityText>)
```

## Description

`Ai.ActivityText` describes the assistant's current activity, such as “Thinking”, “Searching” or “Preparing your answer”. Provide the activity text as `children`. It inherits the surrounding text color.

The current visual treatment uses a moving highlight. When the user prefers reduced motion, the text is shown without animation.

Use [Ai.MessageIndicator](/uilib/extensions/ai/MessageIndicator/) to indicate that an assistant message is being prepared before its content arrives. Use `Ai.ActivityText` when you have a specific activity to describe.
