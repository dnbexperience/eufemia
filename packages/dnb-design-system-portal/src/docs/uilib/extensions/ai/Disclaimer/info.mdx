## Import

```tsx
import * as Ai from '@dnb/eufemia/extensions/ai'
import '@dnb/eufemia/extensions/ai/style'
render(<Ai.Disclaimer />)
```

## Description

`Ai.Disclaimer` shows information at the start of a conversation, like how the chat handles personal data and that AI-generated answers can contain errors.
