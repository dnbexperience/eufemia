## Import

```tsx
import * as Ai from '@dnb/eufemia/extensions/ai'
import '@dnb/eufemia/extensions/ai/style'
render(<Ai.Loader />)
```

## Description

`Ai.Loader` is shown while waiting for the reply, e.g. while the `status` from `useChat` is `submitted`. It has the same header as [Ai.Message](/uilib/extensions/ai/Message/), and screen readers announce a translated text.
