## Import

```tsx
import { PromptInput } from '@dnb/eufemia/extensions/ai'
import '@dnb/eufemia/extensions/ai/style'
render(<PromptInput />)
```

## Description

`Ai.PromptInput` is where the user writes a message. Enter sends the message and Shift+Enter adds a new line. Set `isBusy` while a reply is pending or streaming. With `onStop`, the send button becomes a stop button. The attachment and microphone buttons are only shown when you give their callbacks.

Use `variant="compact"` for a single line with round buttons, e.g. on a welcome screen.
