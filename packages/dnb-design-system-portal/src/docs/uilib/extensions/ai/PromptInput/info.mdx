## Import

```tsx
import * as Ai from '@dnb/eufemia/extensions/ai'
import '@dnb/eufemia/extensions/ai/style'
render(<Ai.PromptInput />)
```

## Description

`Ai.PromptInput` is where the user writes a message. Enter sends the message and Shift+Enter adds a new line. Pass the chat `status` to turn the send button into a stop button while the reply streams in. The attachment and microphone buttons are only shown when you give their callbacks.

Use `variant="compact"` for a single line with round buttons, e.g. on a welcome screen.
