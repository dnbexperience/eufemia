## Import

```tsx
import { PromptInput } from '@dnb/eufemia/extensions/ai'
import '@dnb/eufemia/extensions/ai/style'
render(<PromptInput />)
```

## Description

`Ai.PromptInput` is where the user writes a message. On desktop, Enter sends the message and Shift+Enter adds a new line. On touch-primary devices (`hover: none` and `pointer: coarse`), Enter adds a new line; use the send button to submit. Set `isBusy` while a reply is pending or streaming. With `onStop`, the send button becomes a stop button. The attachment and microphone buttons are only shown when you give their callbacks. After sending, focus returns to the textarea. Stopping also returns keyboard focus when the empty input makes Send disabled or removes it.

Use `variant="compact"` for a single line on a welcome screen. It shows the Aino icon by default and hides the send button until the user enters text. While busy, the stop button stays available even when the input is empty. Use `icon` to change the leading icon or `icon={null}` to hide it.

The default variant is flat and gains a shadow when the textarea is focused. The card uses Textarea hover and focus border colors and thickness; its toolbar buttons retain their own focus styles. The compact variant has a shadow by default; set `dropShadow={false}` for an inline surface or `dropShadow` to elevate the default variant. Keyboard focus remains visible in both variants.

With `disabled`, the card uses Textarea's disabled background and border tokens. Set `textareaProps.status` for error feedback; the card keeps its error border while the textarea is focused.

Pass context chips as `children` to show attachments or references above the input. Your application owns their data and removal actions. Use controls with `type="button"` so removing context does not submit the message.
