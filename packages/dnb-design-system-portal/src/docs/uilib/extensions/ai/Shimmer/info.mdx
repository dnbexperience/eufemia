## Import

```tsx
import * as Ai from '@dnb/eufemia/extensions/ai'
import '@dnb/eufemia/extensions/ai/style'
render(<Ai.Shimmer />)
```

## Description

`Ai.Shimmer` shows a text with a moving shimmer, e.g. while the AI is thinking or uses a tool. It keeps the color of the text around it.

The shimmer stops when the user prefers reduced motion, and the text is shown as normal.
