## Import

```tsx
import { Task } from '@dnb/eufemia/extensions/ai'
import '@dnb/eufemia/extensions/ai/style'
render(<Task title="Looking up your transactions" />)
```

## Description

`Ai.Task` shows work in progress and its outcome, such as looking up transactions or generating a report. It shows a progress indicator while the task runs and a status when it completes, fails or is canceled. Use children for details, controls or a larger result.

Pass a human-readable `title` and a display `status`: `running`, `awaiting`, `done`, `error` or `canceled`. Your application owns the task and maps its state to these values. An AI framework tool call can be one source of that state.

Use children for a useful result, such as a balance or a confirmation, and `errorText` for a user-facing error. The component does not execute work or make requests. For actions requiring confirmation, show `status="awaiting"`, render your confirmation controls as children, and pass the user's decision to your chat implementation.

Use [Ai.AgentAction](/uilib/extensions/ai/AgentAction/) for a compact agent action with progress and optional Undo. Use `Ai.Task` when you need details, controls or a larger result below its status.

`Ai.Task` does not create a live region. Your application owns announcements when status or results change. Use [AriaLive](/uilib/components/aria-live/) for meaningful updates, and avoid duplicating announcements from the surrounding conversation. See [screen reader announcements](/uilib/extensions/ai/integrations/#screen-reader-announcements).
