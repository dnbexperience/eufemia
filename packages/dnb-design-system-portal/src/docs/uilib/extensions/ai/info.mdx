## Import

```tsx
import * as Ai from '@dnb/eufemia/extensions/ai'
import '@dnb/eufemia/extensions/ai/style'
```

## Description

`Ai` provides building blocks for AI chat experiences, built with Eufemia components. Use them to build a chat with an assistant, from the welcome screen with suggestions to the conversation and the prompt input.

## Usage

Pass your messages and chat status to the components. `AiMessageData` describes the message fields Eufemia renders; your chat implementation can keep other fields as well.

```tsx
import * as Ai from '@dnb/eufemia/extensions/ai'
import type {
  AiChatStatus,
  AiMessageData,
} from '@dnb/eufemia/extensions/ai'

type ChatProps = {
  messages: Array<AiMessageData>
  status: AiChatStatus
  onSubmit: (text: string) => void
  onStop: () => void
}

function Chat({ messages, status, onSubmit, onStop }: ChatProps) {
  return (
    <>
      <Ai.Conversation style={{ height: '40rem' }}>
        {messages.map((message) => (
          <Ai.Message
            key={message.id}
            message={message}
            aiGenerated={message.role === 'assistant'}
          />
        ))}
        {status === 'submitted' && <Ai.Loader />}
      </Ai.Conversation>

      <Ai.PromptInput
        status={status}
        onSubmit={({ value }) => onSubmit(value)}
        onStop={onStop}
      />
    </>
  )
}
```

`Ai.Message` renders `text` parts (with `text` and optional `state`), `reasoning` parts (with `text` and `state`), tool parts (with a `tool-` prefix or `dynamic-tool` type), and `source-url` parts (with `url` and optional `title`). Other parts, like files, are not rendered. To show them, give the content as `children` instead of `message`.
