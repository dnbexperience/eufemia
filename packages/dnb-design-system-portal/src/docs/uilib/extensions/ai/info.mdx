## Description

`Ai` provides building blocks for AI chat experiences, built with Eufemia components. Use them to build a chat with an assistant, from the welcome screen with suggestions to the conversation and the prompt input.

## Usage with the AI SDK

The components work with [useChat](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) from `@ai-sdk/react`, but do not depend on it. Install `ai` and `@ai-sdk/react` in your app, and pass the messages and status on:

```tsx
import { useChat } from '@ai-sdk/react'
import * as Ai from '@dnb/eufemia/extensions/ai'

function Chat() {
  const { messages, sendMessage, status, stop } = useChat()

  return (
    <>
      <Ai.Conversation style={{ height: '40rem' }}>
        {messages.map((message) => (
          <Ai.Message
            key={message.id}
            message={message}
            aiGenerated={message.role === 'assistant'}
          />
        ))}
        {status === 'submitted' && <Ai.Loader />}
      </Ai.Conversation>

      <Ai.PromptInput
        status={status}
        onSubmit={({ value }) => sendMessage({ text: value })}
        onStop={stop}
      />
    </>
  )
}
```

`Ai.Message` renders the text parts of a message, reasoning parts as `Ai.Reasoning`, tool parts as `Ai.Tool` and `source-url` parts as `Ai.Sources`. Other parts, like files, are not rendered. To show them, give the content as `children` instead of `message`.
