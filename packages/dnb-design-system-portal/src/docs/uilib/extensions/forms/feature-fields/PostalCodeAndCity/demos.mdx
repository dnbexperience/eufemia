### Non-Norwegian Postal Codes

If you want to allow for a postal code that is not Norwegian, just set the `countryCode` property to the desired country, and add your own custom validation.

NB: As of today, `NO`, `DK` and `CH` get a four-digit postal code mask and validation, and only `NO` limits the city to Norwegian letters, spaces and hyphens. Any other `countryCode` removes these rules, but does not set rules for the given country. This functionality will hopefully be implemented in the future.
