## Demos

### Declarative composition

Use compound React components when the menu structure is authored in JSX.

### Data composition

Use `sections` or `data` to render the same recursive structure from JavaScript objects.
This example is placed inside a `ScrollView` with a viewport-aware maximum height and persists its scroll position in session storage.

<Examples.SidebarMenuData />

### Responsive navigation

The same data renders as a full inline menu on wide screens, a narrow icon rail that expands over the page on hover or keyboard focus at the compact threshold, and behind a hamburger button at the Drawer threshold. `ResponsiveProvider` owns these thresholds, Drawer state, and optional collapsed-inline state, while `ResponsiveDrawer` handles the dialog, focus trapping, Escape key, backdrop, left-side close button, and focus return.

The full `ResponsiveAside` includes `ScrollView`, Portal-style menu spacing, and `ResizeHandle`. Drag its divider, use the arrow keys while it is focused, or press Enter to restore the default width.
Accordion state and ScrollView position persist in session storage.

Drag the demo viewport to the medium breakpoint or narrower to reveal the hamburger button and try the drawer.
