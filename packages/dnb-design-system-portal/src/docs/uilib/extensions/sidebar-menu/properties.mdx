## SidebarMenu.getController

```ts
const sidebar = SidebarMenu.getController(controllerId)

const releaseContent = sidebar.setContent(
  { data: items }, // Or { sections }
  { key: 'app-name' }
)

const removeTransform = sidebar.transformContent((content) => content, {
  key: 'app-name:feature',
  order: 0,
})
```

Returns a controller for `SidebarMenu.Data` instances with the matching `controllerId`. It requires no provider and accepts calls before a menu mounts. Both methods return an idempotent cleanup function. Keys must be non-empty and should identify the owning app and feature. The latest content replacement wins. Transformations run in ascending order, then by key. See [Content controlled by micro frontends](/uilib/extensions/sidebar-menu#content-controlled-by-micro-frontends) for lifecycle and server-rendering behavior.

## SidebarMenu.PreHydrationScript

Renders the blocking script that restores persisted open menu items, scroll position, and desktop dismissal before hydration. It supports standard `ScriptHTMLAttributes<HTMLScriptElement>` except `children` and `dangerouslySetInnerHTML`. Place it after the prerendered menu markup and before the application hydration script.

## SidebarMenu.getPreHydrationScript

Returns the same standalone script as a string for HTML templates assembled outside React.

## SidebarMenu.useResponsive

Returns `SidebarMenuResponsiveValue` with:

- `open`, `setOpen`, `toggle`, and `close` for the small-screen Drawer.
- `isSmallScreen` for the active responsive mode.
- `isCompact` for the icon-rail mode.
- `inlineCollapsed`, `collapseInline`, and `restoreInline` for dismissible desktop navigation.
