## Font roles

[DNB's brand guidelines](https://bc.dnb.no/point/no/dnbvisualguidelines/component/default/763)
define three complementary font families. **Text** is a font variant designed
for readability, used in both digital interfaces and printed documents.

| Font                        | Use                                                                        |
| --------------------------- | -------------------------------------------------------------------------- |
| DNB Sans Text Regular       | Body text, introductions, everyday UI and document content                 |
| DNB Sans Text Medium / Bold | Subheadings; Medium for calls to action                                    |
| DNB Sans Display            | Short, expressive headlines that need extra attention, selected explicitly |
| DNB Sans Mono               | Selected eyebrow labels, short captions and table details                  |
| Arial                       | Fallback when DNB Sans Text cannot load                                    |

Text and Mono provide Light, Regular, Medium and Bold, each with a genuine
italic. The brand guidelines do not assign a specific role to Light. Use
Regular for normal content and ensure sufficient readability when choosing
Light. Display has one upright weight.

Eufemia keeps Text as the default for DNB headings, paragraphs, UI and
letters. Sbanken retains Roboto and Maison Neue. Carnegie retains its
ArizonaFlare headings. Eiendom continues to use the DNB text family.

## Display headlines

### Choose Display for the message, not the heading level

DNB Sans Text is the default for interface and document headings. Choose
DNB Sans Display for short, expressive headlines intended to celebrate
something or draw particular attention to a message.

The following examples apply the brand guidance to interfaces:

- **Consider Display:** a campaign headline, a prominent welcome message,
  or a celebratory announcement.
- **Keep Text:** everyday page and section headings, form steps, dialog
  titles, help content, and letters.

Use Display sparingly so it retains its emphasis. A large heading or an
`<H1>` does not automatically call for Display. Keep the semantic heading
hierarchy independent of the font choice.

Use the font-family option to select Display for a specific headline:

```tsx
import { H1, H2 } from '@dnb/eufemia/elements'
import { Heading } from '@dnb/eufemia/components'

<H1 family="display">En god start</H1>
<H2>Everyday content uses Text</H2>
<Heading family="display">Et steg videre</Heading>
```

<DisplayFontExample />

The equivalent helper is `.dnb-t__family--display`. Custom CSS can use
`font-family: var(--font-family-display)`. The helper uses the single
upright weight, disables synthesized bold and italic, and sets line height
to 110% to allow space for accents and descenders. Check multiline headlines
with Norwegian characters at all supported widths. Increase line height up
to 118% if letters collide. An explicit line-height helper or the Typography
lineHeight property overrides the Display default. DNB Display headings use a
matching skeleton font so loading placeholders keep the same wrapping.
Left-align or center Display headlines. Check wrapping and accented
characters at smaller widths.

Display is never selected automatically by heading level or document
styles. Sbanken and Carnegie map the Display option to their own heading
family. Do not use Display for body text, form labels or controls.

## Typography in general

Fonts are registered by the selected brand basis stylesheet. Load it together with **dnb-ui-core** or **dnb-ui-basis**. Browsers download only the faces used on the page.

Every typography HTML element, like headings and paragraphs, has a defined `height` and `line-height` so everything falls exactly into the **8-pixel grid**.

You don't need to define the `font-family`, but rather use CSS Custom Properties for `font-weight`, `font-size`, and `line-height`.

### Typography property tables

- [font-weight](/uilib/typography/font-weight)
- [font-size](/uilib/typography/font-size)

For embedded app pages, use `<Theme typography="native">` to select the brand's native basis font size. See [native typography](/uilib/typography/font-size#typography-for-native-app-pages).

## Line length

For readable paragraphs and inline help text, keep line length constrained to a comfortable character count.

- Use `var(--prose-max-width)` as the canonical token for maximum text width. Default is `60ch`.
- Base styles and some components expose `var(--prose-max-width)`, which maps to `var(--prose-max-width)`.

### Using the `proseMaxWidth` property (max width in characters)

Prose refers to written text in its natural form, particularly paragraphs and other continuous writing. Typography components like `H2`, `H3`, and `P` support the `proseMaxWidth` property to limit text width based on character count:

```tsx
<H2 proseMaxWidth={80}>
  This heading will be limited to approximately 80 characters wide
</H2>
<P proseMaxWidth={60}>
  This paragraph will be limited to approximately 60 characters wide
</P>
```

### Using `Typography.Context`

```tsx
import { Typography } from '@dnb/eufemia/elements'
```

#### Setting `proseMaxWidth`

Use `Typography.Context` to apply `proseMaxWidth` to multiple typography components at once:

```tsx
<Typography.Context proseMaxWidth={60}>
  <P>This paragraph will be limited to approximately 60 characters wide</P>
  <P>
    This paragraph will also be limited to approximately 60 characters wide
  </P>
  <H2 proseMaxWidth={80}>This heading overrides with its own value</H2>
</Typography.Context>
```

CSS example:

```css
.prose {
  max-width: var(--prose-max-width); /* 60ch by default */
}
```

#### Setting `responsive`

Use `Typography.Context` to make typography components, or all components use responsive font size and line heights.

## Font Face

The default DNB typeface is **DNB Sans Text**, registered under the existing
CSS family name `DNB`. DNB Sans Mono retains the CSS name `DNBMono`.
Keeping these names preserves existing custom CSS and font-family variables.
The stylesheet loads the official `DNBSansText-*` and `DNBSansMono-*`
files, including Light and italics. Display is registered separately as
`DNB Sans Display`.

The existing weights remain Regular (400), Medium (500) and Bold (600).
CSS `bold` (700) also selects the genuine DNB Bold face. Light uses 300.
Use `slant="italic"` or `.dnb-t__slant--italic` for Text and Mono italics.
DNB primary, secondary and tertiary buttons use Medium; unstyled buttons
retain Regular. Built-in selection controls, navigation and clickable file
names also retain Regular; upload and load-more actions use Medium.
Lead and Ingress use Regular in the DNB UI theme.

The faces are declared in `@dnb/eufemia/src/style/themes/ui/fonts.scss`.
Text and Mono use explicit CSS font metrics to keep their baselines
consistent across browsers. Their skeleton fonts use the same metrics.
When self-hosting, keep these declarations along with the font files;
copying the files alone does not preserve the line-box configuration.

- Sbanken uses its own fonts, declared and loaded in `@dnb/eufemia/src/style/themes/sbanken/fonts.scss` and applied via Sbanken-specific properties.
- Carnegie uses the `ArizonaFlare` font family, declared and loaded in `@dnb/eufemia/src/style/themes/carnegie/fonts.scss`, and applied through the Carnegie theme’s typography variables.
- Eiendom uses the default DNB font family.

## Spacing and margin collapsing

You can use the [Spacing properties](/uilib/layout/space/properties) inside every Eufemia React Element, but keep in mind that [margin collapsing](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Box_Model/Mastering_margin_collapsing) can sometimes be a little tricky to get right.

```jsx
import { H1, H2, ... } from '@dnb/eufemia'

<H1 bottom="x-large">Heading with bottom margin: x-large</H1>
<H2 top="x-large">Heading with top margin: x-large</H2>
```

## DNB Sans Mono (monospace)

Use Mono for selected details, such as eyebrow labels, short captions and table values. It is also used for code. Tables keep Text by default; select Mono where it helps the content.

Use it either by a CSS class `.dnb-t__family--monospace` or define your own like so:

```css
.css-selector {
  font-family: var(--font-family-monospace);
  font-weight: normal;
  font-style: normal;
}
```

## Hosted Fonts (CDN)

New Eufemia releases load fonts from an immutable CDN path matching the package
version, for example
`https://assets.eufemia.dnb.no/v<version>/fonts/dnb/DNBSansText-Regular.woff2`.

The stable URLs below always serve the latest stable release and are convenient
when linking fonts manually:

### DNB

- `https://assets.eufemia.dnb.no/fonts/dnb/DNBSansText-Regular.woff2`
- `https://assets.eufemia.dnb.no/fonts/dnb/DNBSansText-Medium.woff2`
- `https://assets.eufemia.dnb.no/fonts/dnb/DNBSansText-Bold.woff2`
- `https://assets.eufemia.dnb.no/fonts/dnb/DNBSansMono-Regular.woff2`
- `https://assets.eufemia.dnb.no/fonts/dnb/DNBSansMono-Medium.woff2`
- `https://assets.eufemia.dnb.no/fonts/dnb/DNBSansMono-Bold.woff2`

Text and Mono filenames follow `DNBSansText-<Weight>[Italic].woff2`
and `DNBSansMono-<Weight>[Italic].woff2`. Weights are `Light`,
`Regular`, `Medium` and `Bold`. WOFF, TTF and OTF are also
included in the package. Display uses `DNBSansDisplay.woff2`.

Download the complete families:

- [DNB Sans Text](https://assets.eufemia.dnb.no/fonts/dnb/DNBSansText.zip)
- [DNB Sans Mono](https://assets.eufemia.dnb.no/fonts/dnb/DNBSansMono.zip)
- [DNB Sans Display](https://assets.eufemia.dnb.no/fonts/dnb/DNBSansDisplay.zip)

These URLs become available with the release containing these files. For
local previews, Eufemia loads the bundled files. The old `DNB-*` and
`DNBMono-*` asset URLs remain available for existing consumers; new code
should use the current filenames. Update manual preloads and self-hosted
copies together with the stylesheet to avoid downloading both generations.
