## Spacing

Eufemia's spacing scale provides named values for margins, padding and gaps through the existing `--spacing-*` CSS properties. Pass the matching names, such as `small` or `large`, to the Space component and component spacing props. These properties are part of Eufemia's established spacing API.

<SpacingTable />

- [Space](/uilib/layout/space/) – margins, inner padding and component spacing props.
- [Responsive spacing](/uilib/layout/space/#responsive-spacing) – spacing that adapts across breakpoints with `Space.ResponsiveContext`.
- [Flex](/uilib/layout/flex/) and [Grid](/uilib/layout/grid/) – layout and spacing between items.
- [Spatial system for designers](/quickguide-designer/spatial-system/) – the 8px grid and spacing guidance.

See the [Spacing guide](/uilib/layout/spacing/) for CSS custom properties and spacing helpers.
