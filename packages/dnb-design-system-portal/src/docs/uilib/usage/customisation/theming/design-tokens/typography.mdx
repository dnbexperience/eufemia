## Typography tokens

Font size and line height come from the Figma brand tokens. Values are defined per brand and color scheme. `--token-font-size-*` controls font size; `--token-font-height-*` controls CSS `line-height`. Both use `rem` so they follow the user's root font size.

</Space>

Use the [font size](/uilib/typography/font-size/) and [line height](/uilib/typography/line-height/) properties for Eufemia's existing size scale and responsive typography. These properties map to the brand tokens in a theme scope. The responsive breakpoint choices remain in Eufemia; the Figma export supplies the values at each chosen size.

The legacy Sbanken `--sb-font-size-*` and `--sb-line-height-*` properties are still emitted. The [v13 migration guidance](/uilib/about-the-lib/releases/eufemia/v13-info/#css-custom-properties-typography) recommends replacing them. Their numeric scale is separate from the brand token scale.
