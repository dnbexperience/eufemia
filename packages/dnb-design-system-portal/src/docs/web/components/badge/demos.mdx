### Setting the `variant` property

#### Information

The default variant. Equivalent to `variant='information'`.

#### Notification

`variant='notification'`.

<BadgeNotification />

<BadgeNotificationNumbers />

<BadgeNotificationInline />

#### Notification indicator

Without `content`, the notification variant is shown as a small dot. Use `label` to describe what it indicates.

<BadgeNotificationIndicator />

### Overlaid badge

You can overlay the badge on top of an element by wrapping the `<Badge>` component around it.

<BadgeInformationAvatar />
<BadgeNotificationAvatar />

#### Overlaid button

The button remains clickable where the badge overlaps it. Use `horizontal` and `vertical` to select the badge corner.

<BadgeButton />

#### Setting property `horizontal` and `vertical`

When overlaying the badge you can control its position.

<BadgeCornerPosition />

### Setting the `status` and `subtle` properties

The information variant has 5 possible `status` values, and two possible `subtle` values.

The default state is equivalent to `status='default'` and `subtle={false}`.

<BadgeStatus />

### Setting the `icon` property

The information variant can show an icon, a country flag or a logo before the content. Primary icons can be set by name, such as `icon="calendar"`. Other icons, a `CountryFlag` or a logo image should be set as React elements.

<BadgeIcon />

### Hiding Badge with `hideBadge`

Sometimes you need to hide the badge without hiding the overlaid element. To make this less complicated you can use the `hideBadge` property.

The example below hides the badge when there are no notifications. You can add or remove notifications with the "+" and "-" buttons.

<BadgeHide />
