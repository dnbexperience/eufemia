## Description

Use Button to start, confirm, or submit an action, such as "Add account" or "Save changes". Use [Anchor](/web/components/anchor) to navigate to another page or section.

## Import

```tsx
import { Button } from '@dnb/eufemia'
```

## Accessibility

Buttons support keyboard interaction: Tab moves focus, and Enter or Space activates the button. Keep the focus indicator visible and use a label that describes the action.

For buttons without visible text, follow the [icon-only button guidance](/web/components/button/demos/#icon-button).

### Click and touch area

Use `bounding` to make a button easier to click or tap without changing its visible size. It adds an invisible area that extends equally on every side by 20% of the button single-line height. For a standard single-line button, this is 20% of its visible height. A wide text button gets the same extra distance on each side as an icon button of the same size. Wrapping or stretching a button does not increase this distance.

For example, at the default root font size:

| Icon button size | Visible size | Area with `bounding` |
| ---------------- | ------------ | -------------------- |
| `small`          | 24 × 24px    | 33.6 × 33.6px        |
| `medium`         | 32 × 32px    | 44.8 × 44.8px        |
| `default`        | 40 × 40px    | 56 × 56px            |

`bounding` does not reserve space in the layout or guarantee a minimum target size such as 44 × 44px. Leave room around the button so its extended area does not overlap another control. An ancestor with `overflow: hidden` or `overflow: auto` can clip the area.

Prefer a larger Button `size` when the layout allows it. If a smaller visible button needs a larger target, customize `.dnb-button__bounding` for that layout and check both the target size and neighboring controls. HelpButton, DatePicker, Card, Tabs scroll navigation, the responsive Breadcrumb toggle, and Chat actions keep their component-specific areas. When overriding the area with `transform`, also set `inset: 0` to reset the default expansion.

## Typography

DNB button labels use DNB Sans Text Regular, matching the Eufemia Web
Figma library. This applies to primary, secondary, tertiary and unstyled
buttons. Built-in selection controls, navigation and clickable file names
also retain Regular. Other brands retain their existing typography.
The text font is shared with other interface content; Display is reserved
for expressive headlines.

DNB labels use normalized font metrics and no additional upward adjustment.
Sbanken retains its existing label adjustment for Roboto. The font weight
and vertical alignment are separate choices; changing the weight is not a
centering correction.
