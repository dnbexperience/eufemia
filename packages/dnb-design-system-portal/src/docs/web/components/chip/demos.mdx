<ChipAddRemove />

### Checkbox

`variant="checkbox"`.

<ChipCheckbox />

### Radio

With `variant="radio"`, only one Chip can be checked.

<ChipRadio />

### With an icon or a flag

Use `icon` for an icon, or `leftComponent` for other content, like a [CountryFlag](/web/components/country-flag). Hide the flag from screen readers with `aria-hidden`, so they only read the text of the Chip.

<ChipIcon />
