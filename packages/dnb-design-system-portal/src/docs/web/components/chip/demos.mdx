## Demos

### Multiple selection

Keep selected values in state when they are used to filter content. Every option remains available after selection.

### Single selection

Use Chip.Group to label and manage mutually exclusive choices. Set `variant="radio"` on the group to show radio indicators, or use the default appearance. Give each chip a unique value.

<SingleSelection />

### Variants and icons

Choose the visual cue that fits the task. In Chip.Group, the selection mode is controlled by `multiselect`, independently of the appearance.

<Variants />

### Group labels, layout, and status

Share selection state and a label with Chip.Group. Use `layoutDirection="column"` to stack the options, `suffix` for guidance, and `status` for a group message.
