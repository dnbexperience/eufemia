## Import

```tsx
import { Chip } from '@dnb/eufemia'
```

## Description

Chip is a compact, selectable option for filters, categories, and short choices. The component name is singular because each instance represents one chip.

Use Chip.Group to manage related choices, their label, and shared name. The group selects one option by default using `value`. Set `multiselect` and use `values` when several options can be selected. Set a shared `variant` on the group to choose the appearance independently of the selection mode. The `addable` variant changes its icon between add and remove as the selection changes. It keeps the chip visible so the user can select it again.

Use [Tag](/web/components/tag/) for compact labels or removable values, [Badge](/web/components/badge/) for counts and statuses, and [Button](/web/components/button/) for actions.

## Toggle buttons

Use Chip like a toggle button to select or deselect an option. Use Chip.Group for mutually exclusive choices, or add `multiselect` to allow several selections. Use Chip for new implementations instead of [ToggleButton](/web/components/toggle-button/), which will be deprecated in a future release.

## Accessibility

Give every chip a short, visible name using `text`, `children`, or `label`, in that order of precedence. Keep the content to text and decorative icons. Links, buttons, and other interactive elements must be outside the chip. An icon, flag, or logo must not be the only way to distinguish options.

Chip uses a native checkbox or radio input. Its selected state is announced by assistive technology and its `name` and `value` participate in native form submission. Only selected, enabled chips are submitted.

Give Chip.Group a visible `label`. A single selection group uses native radio inputs; a multiselect group uses native checkboxes, regardless of the visual variant. Tab moves between checkboxes and enters or leaves a radio group. Space or Enter selects an option; arrow keys move between radio options. Disabled options are skipped. Standalone chips use checkboxes except for the `radio` variant.

Use `status` for an error message that explains how to resolve the problem. `readOnly` preserves the selection while keeping the chip focusable. `disabled` removes it from keyboard navigation and form submission.
