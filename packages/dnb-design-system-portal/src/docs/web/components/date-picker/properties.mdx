### Returned Object

The type of native event will depend on the interaction.
All additional HTML attributes will be returned as well.

```js
{
  date: null | 'date as `returnFormat` | `yyyy-MM-dd`', /* Available if `range` is `false` */
  startDate: null | 'date as `returnFormat` | `yyyy-MM-dd`', /* Available if `range` is `true` */
  endDate: null | 'date as `returnFormat` | `yyyy-MM-dd`', /* Available if `range` is `true` */
  invalidDate: null | 'date as `returnFormat` | `yyyy-MM-dd`', /* Available if `range` is `false` */
  invalidStartDate: null | 'date as `returnFormat` | `yyyy-MM-dd`', /* Available if `range` is `true` */
  invalidEndDate: null | 'date as `returnFormat` | `yyyy-MM-dd`', /* Available if `range` is `true` */
  isValid: boolean, /* Available if `range` is `false` */
  isValidStartDate: boolean, /* Available if `range` is `true` */
  isValidEndDate: boolean, /* Available if `range` is `true` */
  daysBetween: number, /* Available if `range` is `true` */
  attributes: { attributes },
  event: null | { native event }
}
```

## Shortcuts

Each shortcut can have these properties:

- `title`: the text on the shortcut button.
- `date`: the date to set. In range mode, it is used as `startDate`.
- `startDate` and `endDate`: the date range to set. When `endDate` is not set, `startDate` is used.
- `startMonth`: the month to show in the first calendar. Defaults to the month of `startDate`.
- `endMonth`: the month to show in the second calendar, in range mode. Defaults to the month of `endDate`. When it is not a later month than `startMonth`, the month after `startMonth` is shown.
- `closeOnSelect`: if set to `true`, the picker closes when the shortcut is clicked.

The date and month properties accept a date string, a `Date`, or a function that returns a `Date`. The function gets the current `date`, `startDate` and `endDate`.

You may use [date-fns](https://date-fns.org) to make date calculations.
