## Import

```tsx
import { useState } from 'react'
import { Drawer } from '@dnb/eufemia'
```

## Description

The Drawer component is a [Modal](/web/components/modal) variation that appears as a side panel at any chosen side of the page: top, bottom, left, or right (default `right`). A Drawer is typically used to show additional information. It can also be used for easy/quick tasks while staying in context.

### Parts in Drawer

To provide custom content to parts of the Drawer, a set of component parts are provided:

- `<Drawer.Navigation>`: The navigation field at the top of the component, default with a close button (Equal to the property `navContent`).
- `<Drawer.Header>`: The header field of the component, where the `title` will appear (Equal to the property `headerContent`).
- `<Drawer.Body>`: The body of the Drawer, provided with a section background color, default `black-3` (Equal to the property `modalContent`).

### More detailed information

For more details regarding the component functionality, check out the [Modal documentation](/web/components/modal).

### Reveal the page

Import the reveal driver separately to move the page to the right while keeping a left Drawer stationary. The driver also supports dragging right on the page to open the menu and dragging left inside the menu or on the exposed page to close it. Menu links and buttons can still be tapped. Form controls, horizontal scroll areas, and vertical scrolling keep their native interactions.

```tsx
import { Drawer } from '@dnb/eufemia'
import { createDrawerReveal } from '@dnb/eufemia/components/drawer/DrawerReveal'

const reveal = createDrawerReveal({ target: '#app-page' })

function App() {
  const [open, setOpen] = useState(false)

  return (
    <>
      <main id="app-page">Page content</main>
      <Drawer
        open={open}
        onOpen={() => setOpen(true)}
        onClose={() => setOpen(false)}
        renderDriver={reveal}
        containerPlacement="left"
        maxWidth="min(85%, 20rem)"
        title="Menu"
        triggerProps={{ text: 'Open menu' }}
      >
        Menu content
      </Drawer>
    </>
  )
}
```

Create the driver once outside rendering, or memoize it when its options change. The target accepts a CSS selector for one or more page surfaces. Keep the Drawer and its portal outside these surfaces. The driver owns their transform and opacity while the menu is open and restores them on close.

When controlling `open`, synchronize both `onOpen` and `onClose` so a swipe updates your state too. This also lets the app close the menu with `setOpen(false)` after navigation.

The same `renderDriver` property works with `SidebarMenu.ResponsiveDrawer`, which enables it only on narrow screens. Keep a menu button available as an alternative to dragging. Modal focus handling, Escape, backdrop dismissal, and reduced motion remain available.

Ordinary Drawer and SidebarMenu imports do not import the reveal implementation or install its gesture listeners. The reveal JavaScript is included only through the separate import. Reveal styles are included in the Drawer stylesheet.

The mounted reveal driver registers a non-passive document `touchmove` listener to cancel native scrolling during horizontal dragging. Keep work on the main thread short so touch scrolling stays responsive, especially on heavy pages.

## Root Element (React Portal)

The Drawer component uses [PortalRoot](/web/components/portal-root) internally to render its content. See the [PortalRoot documentation](/web/components/portal-root) for information on how to control where the portal content appears in the DOM, and for the [BrowserTranslate helper](/web/components/portal-root/#browsertranslate-helper-google-translate) when browser translation tools such as Google Translate should not modify content rendered through PortalRoot.
