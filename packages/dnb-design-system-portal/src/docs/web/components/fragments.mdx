## Description

Fragments are small, low-level and reusable parts used inside other components.

You may use them only to build new components from.

The deprecated `ScrollView` fragment export remains available for backwards compatibility until v13. Import the [ScrollView component](/web/components/scroll-view/) from `@dnb/eufemia` instead.
