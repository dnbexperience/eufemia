## Properties

| Property        | Type             | Default  | Description                                                                                                                         |
| --------------- | ---------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `value`         | `string`         | Required | Already formatted text to display.                                                                                                  |
| `previousValue` | `string`         | `value`  | Previous formatted text. Omit to display the value without motion.                                                                  |
| `direction`     | `'up' \| 'down'` | `'up'`   | Direction in which changed digits roll.                                                                                             |
| `reserveWidth`  | `string`         |          | Minimum inline size, for example `'6ch'`. Reserves space for the largest expected value and follows the surrounding text alignment. |
| `decorative`    | `boolean`        | `false`  | Generates decorative text when a parent already provides the complete accessible value.                                             |
