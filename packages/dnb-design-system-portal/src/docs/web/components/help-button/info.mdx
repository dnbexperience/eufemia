## Import

```tsx
import { HelpButton } from '@dnb/eufemia'
```

## Description

A help button with custom semantics, helping screen readers determine the meaning of the button. Visually, it is a default [icon button](/web/components/button#icon-button) with the `question` icon as its basis.

This button is used as the default [Modal trigger button](/web/components/modal/demos).
