### Locale based numbers

When you use `asNumber` or `asPercent` (and `asCurrency` see below) it will create a mask for you and inherit the locale from the [Eufemia Provider](/web/usage/customisation/provider), if the locale property is not given.

You can still define extra mask parameters with `numberMask` or `maskOptions`, as the second input example shows (e.g. `decimalLimit`).

<InputMaskedExampleNumberLocale />
