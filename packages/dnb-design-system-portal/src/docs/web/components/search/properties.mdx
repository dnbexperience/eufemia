## Shared properties

These properties apply to `Search.Input`, `Search.Autocomplete`, and `Search.Panel`. All default to `size="medium"`, `labelSrOnly`, and `showClearButton`. A custom `submitElement` or `showSubmitButton` replaces the shortcut hint.

<PropertiesTable props={SearchProperties} />

## Search.Input

Supports [Input properties](/web/components/input/properties) and [events](/web/components/input/events). It defaults to `type="search"` with a loupe icon. Use `value` to update the query, `ref` to access the input, `onChange` for query changes, and `onSubmit` for submission.

## Search.Autocomplete

Supports [Autocomplete properties](/web/components/autocomplete/properties) and [events](/web/components/autocomplete/events). It also defaults to `preventSelection`, `keepValue`, and `noScrollAnimation`. Use `inputValue` to update the query, `inputRef` to access the input, `onType` for query changes, and `onChange` for result selection.

## Search.Panel

Supports the same Autocomplete properties and events as `Search.Autocomplete`, with `openOnFocus` enabled by default. It owns `inline`, `resultsRender`, `skipPortal`, and `preventClose` to compose the results inside the panel. Use `popoverProps` for the supported surface options.
