Choose the contribution that helps your team and other Eufemia users. You can report an issue, improve documentation, suggest a feature, add examples, or submit code.

## Start a contribution

- [Report an issue or make your first contribution](/web/contribute/first-contribution/).
- [Reproduce a bug](/web/contribute/reproduce-a-bug/) with a small example.
- [Follow the local development workflow](/web/contribute/local-development/) to change code or documentation.
- [Read the development principles](/web/contribute/rules/) before introducing new dependencies or APIs.

## Contribution guidelines

- [Code guide](/web/contribute/guidelines/coding/): How to write consistent source code - clean code principles, code formatting for JavaScript/TypeScript/SCSS.
- [Documentation](/web/contribute/guidelines/documentation/): How to write documentation and what to include.
- [Issues](/web/contribute/guidelines/issues/): Template for reporting issues and suggesting new features.
- [Git commits](/web/contribute/guidelines/git/): How to make commit messages, submit PRs, and other Git conventions.
- [Naming](/web/contribute/guidelines/naming/): A list of naming conventions for all languages and variable types.
- [Theming](/web/contribute/guidelines/theming/): How to maintain and create a theme.

## Release and maintenance

- Follow the [release process](/web/contribute/deploy/), including [icons](/web/contribute/deploy/icons/) and [design tokens](/web/contribute/deploy/tokens/).
- Check [troubleshooting and FAQ](/web/contribute/faq/) for local setup and test issues.
- [Preview documentation images](/web/contribute/social-preview-images/) and [suggest a documentation change](/web/contribute/suggest-edit/).

## Community and resources

Ask questions in [#eufemia-web](https://dnb-it.slack.com/archives/CMXABCHEY), [contact the team](/about/contact/), or browse the [GitHub repository](https://github.com/dnbexperience/eufemia).

Read the [brand guidelines](/design-foundations/brand-guidelines/) and the [license](/about/license/) when contributing. Eufemia is a [living design system](/about/how-eufemia-evolves/), improved by its [contributors](/about/eufemia/#special-thanks).
