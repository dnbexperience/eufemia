## Description

A lead paragraph is the opening paragraph of an article, such as a blog post or news story.

## Paragraph class modifiers

Eufemia comes with [several styles](/web/elements/paragraph/#paragraphs-modifiers) you can use on paragraphs and other HTML text elements, where `.dnb-p--lead` is one of them.
