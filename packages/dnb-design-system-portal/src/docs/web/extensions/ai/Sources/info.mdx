## Import

```tsx
import { Sources } from '@dnb/eufemia/extensions/ai'
import '@dnb/eufemia/extensions/ai/style'
render(<Sources />)
```

## Description

`Ai.Sources` shows a collapsible list of sources. Pass `sources` as an array of `{ url, title }` objects. Put it inside `Ai.Message` where the sources should appear. URLs are checked before links are rendered.
