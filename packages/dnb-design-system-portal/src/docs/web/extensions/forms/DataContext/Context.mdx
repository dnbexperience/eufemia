## Description

The main context for [DataContext.Provider](/web/extensions/forms/DataContext/Provider) which the [Field](/web/extensions/forms/base-fields/) and [Value](/web/extensions/forms/Value/) components connect to (optional) for sources and callbacks when it is present. For custom field and value components, prefer [useFieldProps](/web/extensions/forms/create-component/useFieldProps/), [useValueProps](/web/extensions/forms/create-component/useValueProps/) or [Form.useDataValue](/web/extensions/forms/Form/useDataValue/) instead of consuming `DataContext.Context` directly. Direct reads from `data` or `internalDataRef.current` do not create a data subscription.
