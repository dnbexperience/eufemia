## Import

```tsx
import { Form } from '@dnb/eufemia/extensions/forms'
render(<Form.Card />)
```

## Description

`Form.Card` is a wrapper for the [Card](/web/components/card/) component to make it easier to use inside a form:

- It will set `stack` to `true` by default (instead of `false`).

But in all other ways, it works just like the [Card](/web/components/card/) component.
