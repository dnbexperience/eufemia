## Import

```tsx
import { Value } from '@dnb/eufemia/extensions/forms'
render(<Value.Date />)
```

## Description

`Value.Date` is a wrapper component for displaying string values, with user experience tailored for date values.

There is a corresponding [Field.Date](/web/forms/feature-fields/Date) component.

```jsx
import { Value } from '@dnb/eufemia/extensions/forms'
render(<Value.Date />)
```

Check the [Number formatting reference](/design-foundations/number-formatting/) page to see how its locale examples align with what this component renders.
