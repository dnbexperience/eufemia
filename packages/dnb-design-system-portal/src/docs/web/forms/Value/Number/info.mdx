## Import

```tsx
import { Value } from '@dnb/eufemia/extensions/forms'
render(<Value.Number />)
```

## Description

`Value.Number` is a base component for displaying values of the type `number`.

Before using this component, ensure there is not a more specific [value component](/web/forms/Value/components/) available that better suits your needs.

There is a corresponding [Field.Number](/web/forms/base-fields/Number) component.

```jsx
import { Value } from '@dnb/eufemia/extensions/forms'
render(<Value.Number />)
```

It inherits all the properties from the [NumberFormat](/web/components/number-format/) component.

For a locale-by-locale reference that pairs these components with their rendered output, see [Number formatting reference](/design-foundations/number-formatting/).
