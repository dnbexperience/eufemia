## Creating forms

To build an entire form, use surrounding components such as [Form.Handler](/web/forms/Form/Handler/) and [Wizard.Container](/web/forms/Wizard/Container/) to simplify data flow and layout while reducing code complexity without compromising flexibility.

The required styles for Eufemia Forms are included when you import the main Eufemia styles (`import '@dnb/eufemia/style'`) or the theme's `ui-theme-components`; no separate Forms CSS import is needed in these cases.

## TypeScript support

You can define the TypeScript type structure for your form data. This will help you to get better code completion and type checking.

**NB:** Use `type` instead of `interface` for the type definition.

```tsx
import { Form, OnSubmit } from '@dnb/eufemia/extensions/forms'

type MyData = {
  firstName?: string
}

const submitHandler: OnSubmit<MyData> = (data) => {
  console.log(data.firstName satisfies string)
}

function MyForm() {
  return (
    <Form.Handler<MyData> onSubmit={submitHandler}>
      <MyComponent />
    </Form.Handler>
  )
}

const MyComponent = () => {
  const { data } = Form.useData<MyData>()
  return data.firstName
}
```

Read more about TypeScript support and the other methods in the [Form.Handler](/web/forms/Form/Handler/#formhandler) section or in the [Form.useData](/web/forms/Form/useData/#formusedata) hook docs.

To also get autocomplete and compile-time checking on the `path` props of every field and value, see [Type-checked paths](/web/forms/typed-paths/).

## Layout

When building your application forms, preferably use the following layout components. They seamlessly places all the fields and components of Eufemia Forms correctly into place.

- [Flex.Stack](/web/layout-and-typography/layout/flex/stack/) layout component for easy and consistent application forms.
- [Form.Card](/web/forms/Form/Card/) with the stack property `<Form.Card>...</Form.Card>` for the default card outline of forms.
- [Form.Appearance](/web/forms/Form/Appearance/) for changing sizes (height) of e.g. input fields.

## Create your own component

Eufemia Forms consists of helper components and tools so you can declaratively create interactive form components that flawlessly integrates between existing data and your custom form components. This ensures a common look and feel, even when ready-made components are combined with your local custom components.

Read more about [creating your own component](/web/forms/create-component/)
