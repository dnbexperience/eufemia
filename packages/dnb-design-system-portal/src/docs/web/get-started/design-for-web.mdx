Use the official Eufemia Web library in Figma so your designs share the components, typography and spacing used by developers.

## Getting started

1. Open Figma.
2. Make sure you are a member of the DNB UX team. If you need access, [contact the Eufemia team](/about/contact/).
3. Open the team selector.
4. Choose **DNB Bank ASA**.

## Brand guidelines

Read the [DNB brand guidelines](/design-foundations/brand-guidelines/) before starting a design. Use the Eufemia Web library for the interface components and tokens that apply to Web applications.

## Design tools

DNB's interface design templates and guides are maintained in [Figma](https://www.figma.com). Working in the shared tool makes designs easier to review, maintain and hand over.

## Why not Sketch?

The shared Eufemia libraries are maintained in Figma to provide one source for interface design. Teams can choose other tools when their work requires them, but should keep design files and exports accessible to collaborators.

## UI resources

Use the official libraries so your work stays aligned with maintained design resources.
