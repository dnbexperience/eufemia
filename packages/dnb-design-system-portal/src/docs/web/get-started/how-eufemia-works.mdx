The DNB UI library contains ready-to-use HTML elements ([components](/web/components/overview) and [extensions](/web/patterns-and-extensions/extensions)) for existing and new web applications.

The library is the application-development part of the Eufemia design system. It unifies commonly used HTML elements, components, and extensions at DNB and provides a platform for collaborative, continuous improvement.

## What the library provides

- [HTML elements](/web/layout-and-typography/elements) with DNB brand styles, fonts, and icons.
- Ready-to-use [components](/web/components/overview) for common interface needs.
- [Extensions](/web/patterns-and-extensions/extensions) for reusable functionality that does not fit naturally into a standard component, such as Forms.
- [Theming](/web/styling-and-themes/brands-and-dark-mode) for existing and new applications.
- [Accessibility guidance](/web/accessibility) and components built with accessibility in mind.
- Versioned releases and [upgrade guidance](/web/releases-and-upgrades/upgrade) to help applications adopt changes.

The code is automatically checked with integration, static, and snapshot tests, together with tools such as Axe, Stylelint, ESLint, and Prettier. See [Installation](/web/get-started/quick-start) for the technical foundation and supported browsers.

## Design and development

Designers and developers approach interface structure, layout, and sizing from different perspectives. Designers focus on grids, typography, and visual specifications, while developers also need reusability, modularity, flexibility, and scalability.

Eufemia bridges these perspectives through consistent naming, spatial rules, and shared resources. Design resources are based on browser behavior so implemented interfaces closely resemble design handovers. Collaboration through Figma's API, npm, and GitHub keeps design and development connected.
