**Deprecated:** The `--color-*` CSS custom properties and this color documentation are deprecated. Use [Design Tokens – Colors](/web/usage/customisation/theming/design-tokens/colors) instead.

---

Colors are defined in two types:

- Profile (Brand colors)
- UX (Custom web usage colors)

It is recommended to use **CSS Custom Properties name** like `--color-ocean-green` to use a color.

```css
.selector {
  background-color: var(--color-ocean-green);
}
```

See the [Color Table](/web/usage/customisation/colors#colors-table).
