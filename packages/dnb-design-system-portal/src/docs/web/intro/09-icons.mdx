<Intro>

Icons are categories on two [main groups](/icons) and comes in two sizes each:

## [Primary Icons](/icons/primary)

```jsx
<Button icon="chevron_right" text="Button" />
```

## [Secondary Icons](/icons/secondary)

```jsx
import { hamburger } from '@dnb/eufemia/icons'

render(<Button icon={hamburger} text="Button" />)
```

Primary Icons are used inside of other custom [Components](/web/components) and are imported by default.

It is recommended to use the [Icon Component](/web/components/icon) to display icons for best accessibility.
