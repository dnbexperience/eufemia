A commonly used visual style is the DNB section divider. To make it easy to achieve this in your layout setup, have a look at the [Section component](/web/components/section).

## React:

```jsx
import { Section } from '@dnb/eufemia'

render(
  <Section variant="information" spacing>
    Visual DNB Section
  </Section>
)
```

## CSS:

```html
<div
  className="dnb-section dnb-section--info"
  style="padding: var(--spacing-large) 0"
>
  Visual DNB Section
</div>
```

## Demo:
