## Description

Paragraphs are block-level elements used to structure and format text contents.

Paragraph has some default typography styling, even without any properties being set.

Read more [about Fonts in the Designer Guides](/web/layout-and-typography/typography/design-guidance/).

### Typography CSS classes

Both Paragraph and the [Span](/web/layout-and-typography/elements/span/) component have the same typography properties that use the [typography helper classes](/web/layout-and-typography/typography/css-reference/).

To make font sizes and line heights adapt to screen width, use `<Typography.Context responsive>`. See the [responsive typography demo](/web/layout-and-typography/typography/#setting-responsive).
