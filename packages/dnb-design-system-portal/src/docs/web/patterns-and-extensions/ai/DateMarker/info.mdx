## Import

```tsx
import { DateMarker } from '@dnb/eufemia/extensions/ai'
import '@dnb/eufemia/extensions/ai/style'
render(<DateMarker />)
```

## Description

`Ai.DateMarker` shows the date with the weekday, followed by a line, above the messages of that day in [Ai.Conversation](/web/patterns-and-extensions/ai/Conversation/). The date is formatted with [DateFormat](/web/components/date-format/) in the current locale.
