## Translations

| Key                         | Purpose                                                                                            |
| --------------------------- | -------------------------------------------------------------------------------------------------- |
| `undo`                      | Undo button label.                                                                                 |
| `undoTimeLeft`              | Label for the quiet countdown.                                                                     |
| `undoAvailable`             | Announces availability. `%action` is the button label.                                             |
| `undoAvailableFor`          | Announces a time limit. `%action` is the button label and `%seconds` is the remaining time.        |
| `undoAvailableForOneSecond` | Singular form of the time-limit announcement.                                                      |
| `undoAvailableUntil`        | Stable button description. `%action` is the button label and `%time` is the localized expiry time. |
| `undoUnavailable`           | Announces expiry. `%action` is the button label.                                                   |

Status announcements reuse the [Chat.Task translations](/web/patterns-and-extensions/chat/Task/properties/#translations). Application-specific action and result text must be translated by the application. See [Chat translations](/web/patterns-and-extensions/chat/translations/).
