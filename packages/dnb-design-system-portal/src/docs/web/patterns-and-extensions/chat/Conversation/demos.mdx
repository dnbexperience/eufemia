### Reading while content changes

Scroll to earlier messages, then send a new prompt or extend the reply. A new user prompt returns to the end; reading or selecting older content pauses following. Resizing the prompt keeps the latest reply visible when you are following it. Receive message adds an incoming reply; while reading earlier messages, the scroll button shows “New message” and the hook reports unread messages.

<Examples.ChatConversationReading />

### Virtualized history

This opt-in example keeps a window of 1,000 variable-height messages mounted. Try navigating to message 100, appending a turn, extending the latest reply and prepending history. Use Show full transcript for browser search, selection across the full conversation and screen-reader access to unmounted messages.

The example has no real requests. The application owns reply announcements. See [Virtualization](/web/patterns-and-extensions/chat/Conversation/#virtualization) for the tradeoffs and driver import.
