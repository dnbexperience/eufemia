## Import

```tsx
import {
  Conversation,
  Message,
  PromptInput,
  Response,
} from '@dnb/eufemia/extensions/chat'
import '@dnb/eufemia/extensions/chat/style'
```

Import the components and hooks you use by name. The `Chat.` prefix in the documentation identifies the extension; the examples use named imports directly.

### Isolated styles

For applications using [style isolation](/web/usage/customisation/styling/style-isolation/), replace the regular Chat style import with the isolated entry point:

```tsx
import '@dnb/eufemia/style/isolated'
import '@dnb/eufemia/extensions/chat/style/isolated'
import { IsolatedStyleScope } from '@dnb/eufemia/shared'
import { Response } from '@dnb/eufemia/extensions/chat'

render(
  <IsolatedStyleScope>
    <Response>{'Hello from the assistant.'}</Response>
  </IsolatedStyleScope>
)
```

The Chat entry point adds only the extension styles. Keep the isolated basis and theme imports for the Eufemia components used inside it.

## Description

`Chat` provides building blocks for conversations between people, with an AI assistant, or with a handover between the two. Compose messages, a conversation history and an input using Eufemia components. No AI service or chat framework is required.

Use plain text or your own content in `Chat.Message`. Add `Chat.Response` when messages contain markdown. Components such as `Task`, `Confirmation`, `AgentAction` and `Sources` are optional and can represent application operations, decisions and references.

The application owns the participants and their identities. The existing `from="user"` and `from="assistant"` values identify the two conversation sides: `user` is the current user on the right, and `assistant` is the other side on the left, including a human support adviser. They do not determine whether content is AI-generated. Use `name` and `avatar` to identify the sender, and set `aiGenerated` only for content that is actually generated by AI.

## Compatibility with Ai

`Chat` is the new name for the extension previously called `Ai`. Existing `Ai` imports, component types, locale imports and regular or isolated styles remain available as compatibility aliases. Both names use the same components and conversation state. Prefer `Chat` and `@dnb/eufemia/extensions/chat` in new code.

```tsx
import { Chat } from '@dnb/eufemia/extensions'
import '@dnb/eufemia/extensions/chat/style'

render(
  <Chat.Message name="Customer support">How can I help?</Chat.Message>
)
```

Existing `.dnb-ai-*` CSS classes and `--ai-*` custom properties are retained so application styling keeps working. Translation overrides should use `Chat`; legacy `Ai` overrides remain supported, with `Chat` taking precedence when both provide the same key. See [Translations](/web/patterns-and-extensions/chat/translations/) and the [v13 migration note](/web/releases-and-upgrades/versions/eufemia/v13-info/#chat-extension).

## Usage

Your application owns the messages, delivery, participant identities, operation execution and error handling. Eufemia renders the content and handles presentation, keyboard interaction and conversation scrolling.

The message type below belongs to this example. Use your application's data and map it to the component props.

```tsx
import { useId } from 'react'
import {
  Conversation,
  Message,
  MessageIndicator,
  PromptInput,
  Response,
} from '@dnb/eufemia/extensions/chat'
import { GlobalStatus } from '@dnb/eufemia/components'
import '@dnb/eufemia/extensions/chat/style'

type ChatMessage = {
  id: string
  from: 'user' | 'assistant'
  text: string
  isStreaming?: boolean
}

type ChatProps = {
  messages: Array<ChatMessage>
  isBusy: boolean
  isWaiting: boolean
  hasError: boolean
  onSend: (text: string) => void
  onStop: () => void
}

export function Chat({
  messages,
  isBusy,
  isWaiting,
  hasError,
  onSend,
  onStop,
}: ChatProps) {
  const prefix = useId()
  return (
    <>
      <Conversation
        label="Customer support chat"
        scrollBehavior="end"
        style={{ height: '32rem' }}
      >
        {messages.map((message) => (
          <Message
            key={message.id}
            id={prefix + message.id}
            from={message.from}
          >
            {message.from === 'user' ? (
              message.text
            ) : (
              <Response
                parseIncompleteMarkdown={message.isStreaming ?? false}
              >
                {message.text}
              </Response>
            )}
          </Message>
        ))}
        {isWaiting && <MessageIndicator />}
      </Conversation>
      {hasError && (
        <GlobalStatus
          show
          autoScroll={false}
          omitSetFocus
          id={prefix + '-error'}
          text="The reply could not be completed. Try again."
        />
      )}
      <PromptInput
        isBusy={isBusy}
        onSubmit={({ value }) => onSend(value)}
        onStop={onStop}
      />
    </>
  )
}
```

Compose tool results and sources inside each message using `Chat.Task` and `Chat.Sources`. See [Integrations](/web/patterns-and-extensions/chat/integrations/) for complete framework examples and ownership of each state.

Use [Chat.AgentAction](/web/patterns-and-extensions/chat/AgentAction/) for compact agent actions with progress, a result, and optional Undo. The application controls the action state and reversal window.

Use [Chat.Confirmation](/web/patterns-and-extensions/chat/Confirmation/) to ask the user to confirm or decline before proceeding with a proposed action.

## Guides

For human conversations, use `scrollBehavior="end"` to follow the latest messages. Show a MessageIndicator only when your application has a typing signal, and give it a suitable label. See the [human support chat example](/web/patterns-and-extensions/chat/demos/#human-support-chat).

AI integrations can stream markdown and expose tool operations. For streamed-reply announcements, follow the [application-owned announcement recipe](/web/patterns-and-extensions/chat/integrations/#screen-reader-announcements).

- [Translations](/web/patterns-and-extensions/chat/translations/): select a locale and customize component labels.
- [Integrations](/web/patterns-and-extensions/chat/integrations/): composition and recipes for AI SDK and TanStack AI.
