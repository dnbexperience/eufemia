## Choose a solution

Use a **pattern** when existing components can be composed to solve a recurring interface problem. Patterns explain when and how to combine those components; they do not add a separate API.

Use an **extension** when you need a reusable solution with its own API, such as Forms, SidebarMenu or TableOfContent. Extensions build on Eufemia components and provide behavior for a larger part of an application.

## Import extensions

```tsx
import { SidebarMenu, TableOfContent } from '@dnb/eufemia/extensions'
```

## Extension styles

Some extensions require additional styles. Follow each extension's import instructions. For example:

```tsx
import '@dnb/eufemia/extensions/sidebar-menu/style'
import '@dnb/eufemia/extensions/table-of-content/style'
```
