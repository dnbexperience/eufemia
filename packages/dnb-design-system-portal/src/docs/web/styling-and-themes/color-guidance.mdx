Use colors by their purpose: text, surfaces, borders, actions, and feedback. Eufemia's current color system is shared through semantic design tokens.

- [Browse current colors](/web/styling-and-themes/design-tokens/colors/).
- [Choose colors by their role](/web/styling-and-themes/design-tokens/guide/).
- [Design for dark mode](/web/styling-and-themes/design-tokens/dark-mode/).
- [Check accessibility and contrast](/web/accessibility/design-guidance/).

For implementation, see [Web design tokens](/web/styling-and-themes/design-tokens/). The [legacy palette](/web/styling-and-themes/legacy-colors/#legacy-color-palette) and [legacy CSS colors](/web/styling-and-themes/legacy-colors/) remain available for older applications.
