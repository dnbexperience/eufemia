## Spacing

Eufemia's spacing scale provides named values for margins, padding and gaps through the existing `--spacing-*` CSS properties. Pass the matching names, such as `small` or `large`, to the Space component and component spacing props. These properties are part of Eufemia's established spacing API.

<SpacingTable />

- [Space](/web/layout-and-typography/layout/space/) – margins, inner padding and component spacing props.
- [Responsive spacing](/web/layout-and-typography/layout/space/#responsive-spacing) – spacing that adapts across breakpoints with `Space.ResponsiveContext`.
- [Flex](/web/layout-and-typography/layout/flex/) and [Grid](/web/layout-and-typography/layout/grid/) – layout and spacing between items.
- [Spatial system for designers](/web/layout-and-typography/layout-principles/) – the 8px grid and spacing guidance.

See the [Spacing guide](/web/layout-and-typography/spacing/) for CSS custom properties and spacing helpers.
