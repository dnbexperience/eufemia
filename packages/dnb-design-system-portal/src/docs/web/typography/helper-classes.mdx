This is a list of all the typography helper classes available. They are used by the [Span](/web/elements/span) and [Paragraph](/web/elements/paragraph) components, but can also be used on their own.

For visual examples, see the [Paragraph demos](/web/elements/paragraph/#demos).

For details on sizes and weights, see the [Font weights](/web/typography/font-weight/), [Font size](/web/typography/font-size/) and [Line Height](/web/typography/line-height/) documentation.

## CSS classes `.dnb-t`

### Font weight

```
  .dnb-t__weight--regular
  .dnb-t__weight--medium
  .dnb-t__weight--bold
```

### Font size

```
  .dnb-t__size--xx-large
  .dnb-t__size--x-large
  .dnb-t__size--large
  .dnb-t__size--basis
  .dnb-t__size--medium
  .dnb-t__size--small
  .dnb-t__size--x-small
```

### Line heights

```
  .dnb-t__line-height--xx-large
  .dnb-t__line-height--x-large
  .dnb-t__line-height--large
  .dnb-t__line-height--basis
  .dnb-t__line-height--medium
  .dnb-t__line-height--small
  .dnb-t__line-height--x-small
```

### Text alignment

```
  .dnb-t__align--center
  .dnb-t__align--left
  .dnb-t__align--right
```

### Font family

```
  .dnb-t__family--default
  .dnb-t__family--heading
  .dnb-t__family--monospace
```

### Underline / italic

```
  .dnb-t__decoration--underline
  .dnb-t__slant--italic
```
