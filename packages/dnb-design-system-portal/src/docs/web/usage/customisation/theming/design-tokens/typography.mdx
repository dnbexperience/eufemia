## Typography

The Figma brand exports supply Eufemia's font sizes and line heights. Use the existing `--font-size-*` and `--line-height-*` CSS properties; their values follow the selected brand. These properties are Eufemia's established typography API. Light and dark mode use the same typography values.

- [Font sizes](/web/typography/font-size/) – CSS properties, values by brand, and responsive sizes.
- [Line heights](/web/typography/line-height/) – CSS properties, values by brand, and responsive line heights.
- [Font weights](/web/typography/font-weight/) – the weight scale and its CSS properties.
- [Typography for designers](/quickguide-designer/fonts#typographic-elements) – DNB typographic examples.

Responsive typography uses these brand values at Eufemia's existing breakpoints. See the font-size and line-height tables for the values used by `<Typography.Context responsive>`.
