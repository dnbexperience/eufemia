Set up Eufemia in your application, check browser support, and choose your next learning step. For a shorter introduction with a working component example, follow the [quick start](/web/getting-started).

The library provides self-contained building blocks with the styles needed for display:

- **HTML elements** are styled HTML tags.
- **UI components** are styled and custom-built HTML elements.
- **UI extensions** add reusable functionality to Eufemia.

Each supports the customization properties shown in its documentation.

## Good to know

Read the [Web introduction](/web/introduction) for the library's purpose, capabilities, and design/development approach.

## Installation

Install `@dnb/eufemia` together with [React](https://www.npmjs.com/package/react) and [React DOM](https://www.npmjs.com/package/react-dom):

```bash
npm i @dnb/eufemia react react-dom
```

This saves the packages in your **package.json** dependencies. Import the styles once in your application entry:

```js
import '@dnb/eufemia/style'
```

See [Importing CSS](/web/usage/customisation/styling/consume-styles) for more style-loading options.

## Technical foundation

Eufemia's components are built with [React](https://react.dev/) for reusable, deeply tested interfaces. The library is published on [npm](https://www.npmjs.com/package/@dnb/eufemia) with versioned releases.

Documentation examples use modern JavaScript syntax. The production JavaScript is transpiled for the [supported browsers and platforms](#supported-browsers-and-platforms) listed below.

### Configuration and Browserslist

Eufemia uses the [@dnb/browserslist-config](https://github.com/dnbexperience/browserslist-config) configuration for bundle output, defined in `.browserslistrc`:

- `extends @dnb/browserslist-config`

This configuration only affects the JavaScript bundle output, not the CSS bundle output.
