The savings artwork comes from the Media card in the Eufemia Web Figma file:
https://www.figma.com/design/cdtwQD8IJ7pTeE45U148r1/?node-id=70914-1390

`savings.webp` is an optimized copy of that artwork. `savings-loop.mp4` is a six-second, silent zoom loop made from the same image for the documentation example. It uses a continuous subpixel transform at 60fps to avoid whole-pixel resize/crop jumps. It is not the original footage shown in Figma. Use approved product media in applications.

`savings-poster.webp` is extracted from the video's first decoded frame and uses the same dimensions and crop to avoid a jump on playback.
