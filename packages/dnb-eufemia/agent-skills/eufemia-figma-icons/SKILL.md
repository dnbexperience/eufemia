# Eufemia Figma Icons

When adding or refreshing icons from the Eufemia Figma Icons Library, read and follow this repository documentation before acting:

`packages/dnb-design-system-portal/src/docs/contribute/deploy/icons.mdx`

When preparing a PR for new icons:

- Use `feat(Icons): add [icon names]` as the title format.
- Keep the description to one short sentence.
- Add genuinely new icon names under the intended release date in `packages/dnb-design-system-portal/src/docs/EUFEMIA_CHANGELOG.mdx`, using the existing date-heading and `New [Icons](/icons/secondary):` formats.
